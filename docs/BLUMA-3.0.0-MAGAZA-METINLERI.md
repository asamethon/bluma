# Bluma 3.0.0 App Store ve Play mağaza metinleri

5 Eylül 2026'da hazırlandı. Tüm karakter sayıları python ile doğrulandı (aşan alan yok).
Apple ID 6749180146 · com.d4tecompany.bluma (Play, D4TE Company hesabı).

## Nasıl kullanılır

- **iOS'ta arama sıralamasını yalnızca 3 alan belirler: Name (30) + Subtitle (30) + Keywords (100).** Açıklama İNDEKSLENMEZ; o bir dönüşüm metnidir, ASO metni değil.
- **Play'de tam açıklama İNDEKSLENİR.** O yüzden Play tam açıklaması ayrı yazıldı ve anahtar kelime yoğunluğu bilerek yüksek tutuldu.
- Name ve Subtitle'daki kelimeler keyword alanına TEKRAR YAZILMAZ. Aşağıdaki setlerde bu kural uygulandı.
- Keyword alanında **virgülden sonra boşluk yok**, çünkü boşluk karakter yer.
- Apple ön ek eşlemesi yapar: indeksli `hikayeler`, `hikaye` sorgusunu yakalar; tersi olmaz. Bu yüzden çoğullar keyword'de tutuldu.
- **Hiçbir dilde rakip marka adı yok** (Wattpad dahil). Apple 2.3.7 ve Play politikası ihlali; reddedilme = gecikme.
